| 场景/指标 | 目标 |
| --- | --- |
| 清晰中文 CER | ≤15% |
| 噪声或远场中文 CER | ≤30% |
| 人工标注起止点的绝对误差 P95 | ≤1500ms |
| 样本划分 | held_out，不参与调优 |

按主项目要求去除 Unicode 标点和空白，保留数字与专业术语，P95 使用 nearest_rank；正式接入用主项目检查工具，不另设放宽条件。当前最长 40 秒音频块不是句级对齐，不能直接认定时间门槛通过。

已固定主项目原版计算器及门槛于 integration/upstream/。integration/quality.py 提供参考集冻结及指标检查，防止改动参考文字、人工时间点或来源后沿用旧摘要。运行脚本及合成演练见 integration/README.md；合成达标始终 acceptance_passed=false，退出1。当前没有真实中文素材，任何计算器测试通过都不记入以下真实验收表。

## 六维报告人工核对

固定输入、模型和规则，条件允许时两位熟悉学科的人独立核对并记录分歧：

1. 事实是否有原文，角色、预告与已发生是否区分，是否漏读上下文。
2. 分析是否保留条件，是否将可能价值写成实际成效，或把未录到写成教师没做。
3. 建议是否针对本段，有具体动作，是否重复已有讲解，是否增加未经核实的标准答案。
4. 观察方法能否检查学生回答或作品，是否明确属于未来验证。
5. 是否覆盖人工标出的重要做法；不能靠少输出换取表面高支持率。
6. 全文疑点是否误报或漏报；没有提醒不等于人工通过。

## 留档与对照

同一转写比较版本，不以变短或建议变多作为提升依据；保留失败，不覆盖旧报告。记录输入版本、规则指纹、用量、耗时与账单，不自动重试可能计费请求。
