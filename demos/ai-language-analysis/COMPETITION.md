# 参赛方案与演示初稿

更新日期：2026-10-20。本文供团队参赛材料参考，尚未逐项对照官方评分表。真实中文质量、教师评价及主系统集成待验收，不填写未经测量的准确率、耗时或节费比例。

## 方案定位

面向教师课后复盘，从已获准录像获取 ASR 转写，围绕内容、节奏、思维、表达、管理、技术生成六维反馈。先说明本段讲了什么，再给有来源的课堂事实、教学分析与具体修改方向。

Go 实现服务和校验，原生网页展示；正式接入复用主项目的 Go 业务、媒体 Worker 及 React。视频当前只用于回看，无计算机视觉判断，不输出教师能力分数。

## 已实现的展示点

1. 停顿弹性切片与块级时间；保守阅读整理，原始转写保留。
2. 原话、事件、结论与回放可关联；引用校验不等于语义认证。
3. 原始与修订转写、报告历史分别保存；修订后文本重分析复用 ASR。
4. 后台进度、取消、检查点与人工重试；可能计费的请求不自动重试。
5. 左侧导航分区阅读，事实、分析、建议和实施后观察方法直接展示；教学推进附已保存事件的讲解脉络。
6. 全文检查明确具体疑点，正文仍完整可读；人工校对单独记录，不代替正式发布。

未录到学生回答不等于没有互动，提问不证明学生已掌握，工具提及不证明真实效果。证据不足维度保留限制。

## 五分钟演示

| 时间 | 内容 | 说明 |
| --- | --- | --- |
| 第 1 分钟 | 已授权短片段与处理阶段 | 准备已完成任务，避免网络等待影响演示 |
| 第 2 分钟 | 原始转写、连续阅读、原文回放 | 当前最长 40 秒块级定位 |
| 第 3 分钟 | 概览、六维导航、讲解思路 | 脉络来自已有事件，不推断未发生教学 |
| 第 4 分钟 | 一条分析与具体建议，一条待确认表述 | 区分课堂事实、未来建议和模型疑点 |
| 第 5 分钟 | 修订、历史、导出及校对记录 | 重跑需确认费用，校对不自动重新生成 |

无网络或无调用预算时展示保存的结果，不伪装成实时成功。

## 验证与不足

工程检查使用本地模拟接口和合成媒体。公开英语物理/生物历史资料用于固定失败回归，见 testdata/public-courses/，保留来源及使用条件；它们不是教师金标准，也不能证明当前规则准确率。

另有主项目候选离线适配、原版 Schema 契约测试与冻结参考/质量计算工具。Windows隔离启动及Linux交叉编译已验证；Docker实际运行、正式数据库/Worker接入和真实中文质量尚待完成。工程交付物见 integration/README.md。
