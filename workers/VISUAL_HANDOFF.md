## 1. 现有视觉结果导出

已有 `analyze-local` 报告可直接导出，不重跑模型、不连接 Go，也不复制原视频：

```powershell
python -m workers export-visual '<本地分析输出>/report.json' --output var/visual-handoff
```

输入只读，输出必须是报告目录之外的新目录。默认包含报告实际引用的原图/标注图，总量限 512 MiB、单张限 10 MiB。图片按内容摘要保存并去重；存在危险路径、链接、缺失图片或超限时拒绝成功导出。大报告可显式使用 `--without-images`，此时图片标为 `not_included`，不能当作已有画面证据。

如果已由 Go 提供对应课堂、批次和媒体编号，可成套绑定，不能编造编号：

```powershell
python -m workers export-visual '<本地报告>/report.json' --output var/bound-visual-handoff --session-id '<课堂UUID>' --run-id '<批次UUID>' --media-asset-id '<媒体UUID>'
```

绑定本身不等于授权或入库；未来消费者必须通过 Go 核对归属、源录像摘要、代次和权限。

### 结果字段

主文件为 `visual-handoff.json`，格式名 `visual-handoff-v1`；它是联合接入包，**不是正式 StageResult，也不能发给当前 complete 接口**。纯合成结构样例见 [样例文件](examples/visual-handoff.synthetic.json)，其中的行为不是模型实测。

| 字段 | 含义 |
| --- | --- |
| source / source_report_sha256 | 原录像摘要、时长及尺寸；原始本地报告摘要 |
| binding | Go 提供的课堂/批次/媒体编号；未提供则 null |
| counts | 每次实际检查画面的可见人数和行为人数；unknown 保持 null |
| persons[].track_id | 此段录像的匿名编号；遮挡和切镜后可能变号，不是学籍身份 |
| persons[].observations | 原录像整数毫秒、框、四类机器判断、分数、可判断条件和本地复核记录 |
| persons[].observation_counts | 每类行为的 positive/negative/unknown 画面数；不是动作次数 |
| events | 既有算法生成的持续候选、起止时间、匿名编号及证据引用，不额外拼接或补造事件 |
| images | 实际复制的图片、SHA-256、相对路径、原录像时间及原图/标注图类型；不冒充 Go asset_id |
| execution / weights / configuration | 原分析执行器、模型摘要、规则和配置，非导出时重新推理 |

机器判断与本地复核分别保留，例如机器为 true、本地复核为 false 时不覆盖机器原值。本地复核尚未经过团队登录授权，不能直接当成正式复核结果。框坐标为源图像像素；时间以原录像起点为零，不使用剪辑片段起点，也不把帧号当毫秒。

## 2. 带音轨、横竖屏媒体验收

真实 Go `1af89a5`、PostgreSQL 17.6 专用 `cangjie_worker_integration` 库、Python 3.12 Worker，未加载视觉模型或启用 GPU。

| 合成输入 | 真实接口检查 |
| --- | --- |
| 普通与奇数宽度 H.264 无音轨 | 上传→probe→代理→授权 Range→关键帧→Go 画面证据 |
| 横屏 H.264/Opus，320×240，4 秒 | 上传→probe→代理 ready、保留音轨、授权 Range、关键帧原时间点 |
| 竖屏 H.264/AAC，240×320，4 秒 | 同上，保留竖屏物理尺寸 |
| 暂存清理与回执 | 独立 Worker 暂存清理、真实回执及 Go 删除完成 |

四种媒体子用例合计 20.01 秒，清理用例 3.50 秒。单个 probe 约 0.85～1.28 秒，单个关键帧阶段约 0.59～0.61 秒。独立 Python 测试另核对代理为 H.264/AAC、逐帧时间映射及音轨起点，竖屏仍遵守配置的高度上限，未偷偷降画质或放宽限额。

带音轨的 full 批次在没有 ASR Worker 时如实保持 audio_analysis queued，不伪造转写或报告。测试完成视频阶段后通过正式取消接口收口待执行批次；这不等于完整 ASR/六维报告通过，也不能用 queued 批次证明分析已经结束。

CI 保留旧 phase4 媒体兼容，并将最新后端固定到上述 main 提交，避免继续只测手机采集合入前的旧后端。原真实联调入口与专用数据库保护见 [README](README.md)；测试夹具和 Go 测试均不进入正式业务代码。

## 3. 导出性能和质量边界

使用既有 4 秒密集录像报告：8 张采样画面、51 个匿名编号、372 次人物观察，复制 16 张图片共 1,153,479 字节，导出和逐项核对合计 0.163 秒。人数曲线、人物时间、框、机器三值及事件起止与源报告相同；源报告保持只读，没有再次加载模型。该数字只表示已有报告的导出开销，不能当作视频识别耗时或证明 51 个真实学生。

真实记录和图片仅留在忽略的 var/；仓库样例只用虚构编号和合成结构。
