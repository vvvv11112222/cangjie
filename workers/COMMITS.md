- 真实近景和密集录像完成 P0 模拟 HTTP 联调；源录像、播放代理、关键帧时间与协议回传均检查通过。模拟服务不是正式 Go 后端。
- Git 中不包含真实课堂媒体、人物明细、人工标签、模型权重或登录凭据。

### 速度和原示例结果对照

相同显卡、模型、参数和每秒检查 2 次画面；没有减少检查人数、降低分辨率或关闭低头等功能。

| 录像长度 | 原示例分析 | 团队版分析 | 结果比较 |

| 17.433 秒 | 13.281 秒 | 10.817 秒 | 214 次人物观察一致 |
| 30.376 秒密集课堂 | 45.603 秒 | 42.787 秒 | 2,888 次人物观察一致 |
| 120.376 秒密集课堂 | 218.148 秒 | 180.529 秒 | 11,588 次人物观察一致 |

总计 14,690 次人物观察及全部报告结果字段一致，排除耗时与运行来源字段。时间轴修正后的完整分析也按源帧对照一致。上述单轮测试达到“迁移不降低原示例结果和速度”的最低要求，不能据此承诺所有机器都同速，也不是人工准确率验收。

2 分钟录像本地完整流程实测 **184.657 秒**，含准备播放视频、加载模型、视觉分析、证据和多格式报告导出；不含尚未接通的 Go 上传与六维报告链路。**120 秒内完成的目标尚未达到**。姿态推理仍是主要耗时环节，详见 [VALIDATION.md](VALIDATION.md)。
