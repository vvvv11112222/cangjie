# 主项目模型配置工具

本工具补充 [统一音视频接入](音视频统一接入与收尾.md) 的配置步骤，不替换现有 Worker、任务、预算或报告服务。适用于已在独立 demo 验证百炼语音和文本调用、需要接到主项目的部署者。对应 FR-07、FR-08、FR-11。

## 本机简化配置入口（2026-10-22）

已准备好团队网页的电脑可双击仓库根目录 **配置语音与报告.bat**，无需先创建独立Demo配置。它读取本部署已记录的Python路径，不依赖Codex。服务须已启动，且没有排队/运行中的任务；工具不会取消用户分析。

1. 在[百炼官方密钥指南](https://help.aliyun.com/zh/model-studio/get-api-key)所述控制台，用自己的账号开通华北2（北京）服务并创建API Key。登录、实名或服务协议由账号持有人完成；不要把密钥发到聊天或GitHub。
2. 在本机配置窗口粘贴密钥，输入明确允许的应用本月人民币预算；不输入金额或按Ctrl+C会取消，没有默认正数额度。密钥不回显，支持带句点的新版业务空间密钥；只粘贴密钥本身，不带引号或其他配置文字。
3. 工具离线校验并保存新的本地私有配置，保留原账号与数据，然后重新prepare/start；不自动调用模型测试。只有之后提交获准课堂分析才可能产生模型费用。

选用 `qwen3-asr-flash`（语音）和 `qwen-plus-2025-12-01`（报告），共用北京兼容接口。语音型号是供应商滚动别名，配置记录同名标识，不声称固定权重；新配置留空language_hints使用供应商自动语种识别，按官方ASR示例只发送必要音频和enable_itn=false，不给按秒ASR额外发送max_tokens。报告使用非思考请求，输入上限8000 token、输出上限6000，处于所核对价格的首档。实际账号可用性、请求参数和识别质量须凭自己的密钥及获准短录像实测；没有密钥时不能标为已开通。

[官方价格表](https://help.aliyun.com/zh/model-studio/model-pricing)于2026-10-22核对：该北京语音模型0.00022元/秒、输出不计费；报告首档输入0.8元/百万token、非思考输出2元/百万token。工具把语音明确设为seconds计费、220微元/秒，未转换为虚假的token单价；价格或地域变化须更新配置后再用。应用按配置标价记账，不保证供应商折扣、试用额度和其他程序的账户费用，也不承诺实际账单绝不超出本地预留。旧配置文件不覆盖；临时密钥输入文件用完删除。

配置成功后：课堂详情选中录像 → 来源须已核验analysis及云端处理用途 → **语音转写与教学报告**。完成后“转写”显示文字和对应原录像时间段，可人工修订；“报告”显示六维教学观察、证据引用及建议。报告先是草稿，须逐条复核和整篇确认，具发布权限的人发布后才可正式导出。此流程不会补造此前只做视觉分析的音频结果。

新生成的配置默认使用综合模板 `teacher-sixdim-v2`，会固定教务/课表背景，复用同一录像已完成的举手与低头结果。使用顺序：先完成“举手与低头识别”，再提交语音与报告；已有转写时，在转写修订区域点击“用此版本重新生成报告”，只调用报告模型，不重复识别语音或视觉。报告显示实际采用的材料，缺少课表或视觉时明确说明。原v1配置及已存在的报告不会自动变成综合报告，旧模板仍可加载；需要按上述步骤生成新的v2配置、重启后创建新报告。

## 当前接入方式

视频提取音轨由本地 FFmpeg 完成，不需要上传模型权重。Python 音频 Worker 调用原语言模块的切片工具，将音频块发送到 Go 内部接口；Go 验证许可、租约和共享预算后调用云 ASR。转写成为正式证据后，Go 调用报告模型生成六维草稿。教师继续通过原有页面复核，不会自动发布。

主项目与独立 demo 的配置名称不同。本次增加 `cmd/model-config`：将明确指定的 demo 配置转换为主项目已有的 ASR/REPORT/MODEL 设置，自动核对内置教师报告提示词摘要、价格单位、模型和地址绑定、单次费用预留。所有配置工具命令均离线运行，不连接数据库、不测试云端连通性、不产生模型费用、不启动分析。

## 暂不核对价格时，先做无付费联调

价格可以暂缓核对，不妨碍验证工程链路。保留价格表 confirmed=false，不生成启用配置，不填写虚假单价，也不关闭主项目预算保护。下面的集成测试自行创建本机模拟模型端点，不读取真实模型密钥，不向真实供应商发请求；其中的模型名称、价格和语音回答均为合成数据。

先安装 Go、Worker 媒体依赖并构建切片工具，按 [统一接入说明](音视频统一接入与收尾.md) 准备环境。在仓库根目录执行，所有路径和数据库地址替换为部署者自己的值：

```powershell
$env:TEST_DATABASE_URL = '<独立测试数据库连接串>'
$env:WORKER_AUDIO_PYTHON = '<已安装 Worker 依赖的 python.exe 绝对路径>'
$env:WORKER_AUDIO_PLANNER = '<已构建 audio-plan.exe 的绝对路径>'
$env:PYTHONUTF8 = '1'
go test ./internal/httpapi -run '^TestAudioWorkerMainPipeline$' -count=1 -v -timeout=5m
```

注意：该测试会迁移并清空测试库中的相关业务表，只能使用可丢弃的独立测试库，绝不能填写业务数据库。缺少数据库或 Worker 环境变量时 Go 会显示 SKIP；SKIP 不表示链路通过。测试启动临时 HTTP 服务及 Worker 子进程，完成后关闭；不需要停止已有服务。

通过标准覆盖整条交付流程：

| 环节 | 自动核验内容 |
| --- | --- |
| 视频到转写 | 45 秒合成录像经真实 Python Runner、FFmpeg 和切片工具处理，保留 1 秒音轨延迟；两块模拟 ASR 文本正式入库 |
| 六维草稿 | 使用内置教师报告提示词，六维齐全；建议正文及引用保留，证据属于本次课堂、媒体和批次，时间与转写在原视频轴上一致 |
| 人工复核 | 初始观察为未复核；草稿不能导出，未完成复核不能发布；逐条确认与整篇确认后，只有具发布权限的账号可以发布 |
| 正式下载 | 同键重放不重复创建导出任务；下载保留固定发布版本、建议、复核状态及有效证据引用 |
| 权限与调用次数 | 其他账号不能读取该请求者的下载；撤销来源 export 用途后旧地址失效；复核、发布、导出不会再请求模型 |

自动测试中的复核确认仅是测试动作，不是学科人员对真实课堂报告的认可。JSON 导出保留证据 ID 与可用性，不承诺导出包包含原录像或完整转写；视频时间点在正式 results 接口核验。通过此测试仍不代表中文识别质量、供应商计费或实际部署通过。价格核对留待真实收费联调前完成即可。

## 1. 先核对价格，不能照抄示例价格

在主项目根目录执行，预算替换为部署负责人已经同意的金额；这里的 30 元只是演示。

```powershell
go run ./cmd/model-config init-pricing -budget 30 -output var/model-setup/pricing.json
```

价格表默认 `confirmed=false`，没有密钥，不会启用调用。填写同地域、同模型、相应 token 档位的实际价格及来源，核对完成后才改成 true。

| 字段 | 填写说明 |
| --- | --- |
| api_base、asr_model、report_model | 必须与指定 demo 配置一致，避免地域或模型不同而套用错误价格 |
| asr_revision、report_revision | 供应商实际模型版本或修订标识；若只提供可变别名，要明确记录别名限制，不能声称固定了权重版本 |
| 四个 *_cny_per_million_tokens | 人民币每百万 token 的输入/输出价格，最多六位小数；不能填“元/分钟”或“元/千 token”而不换算 |
| monthly_budget_cny | 管理员同意的共享月预算，语音与报告一起占用 |
| price_source、price_version | 本地保留的控制台/官方价格来源及地域、档位、核对日期；不包含登录令牌 |
| confirmed | 只有实际核对后才设 true；工具不证明填入的价格与供应商账单相符 |

按音频时长计价的 ASR 使用 asr_billing_mode="seconds" 和 asr_cny_per_second（元/秒），不填写虚构的输入/输出 token 单价。生成的 ASR_PRICE_PER_SECOND_MICROS 为每秒人民币微元；服务按每块已验证音频时长向上取整秒预留，并只用供应商 usage.seconds 结算。缺少、为零、非法或超过40秒的计费时长保留 unknown，不能从 token 数推算或自动重发。未指定计费方式的历史配置继续按 token 执行。长课价格可能分档，需结合实际输入上限核对，不以工具的静态校验代替供应商计费规则。

## 2. 生成并检查主项目私有配置

路径替换为自己的文件；不要在终端命令中填写密钥。prepare 只读取明确指定的 demo .env，不使用环境中另一份百炼密钥，也不修改源文件或主项目 .env。

```powershell
go run ./cmd/model-config prepare -demo-env '<demo目录>/.env' -pricing var/model-setup/pricing.json -output var/model-setup/analysis.private.json
go run ./cmd/model-config check -config var/model-setup/analysis.private.json
```

prepare 先验证价格，再读取密钥。它仅为当前 demo 共用服务地址/密钥的模式生成配置；不同服务商或分开使用密钥的部署可按原文档自行填写私有 JSON，再 check。JSON 值均为字符串。ASR 单价自动转换为主项目的每百万 token 微元整数，报告单价保持人民币单位。价格、模型修订或必填项未核对时拒绝生成，不用默认假价格。

输出包含 `configuration_valid`、模型名称、月预算和 `keys_configured`；不输出密钥。`provider_connection_tested=false` 和 `billed_calls=0` 表示没有调用模型，不代表云端权限、额度或参数已实测通过。已有输出文件不覆盖，修改时使用新文件名；变更确认后再切换部署引用。

生成文件以 .private.json 结尾并被 Git 忽略，仍应放在受控目录。文件创建权限使用 0600；Windows 的实际访问控制还需由本地账号和文件夹 ACL 保证。不要发送整个文件、完整 .env 或未脱敏截图给队友。

## 3. 主项目加载配置

原生 Go 启动，在已经具备数据库、迁移、Worker 和前端的主项目环境中执行：

```powershell
$env:MODEL_CONFIG_FILE = (Resolve-Path var/model-setup/analysis.private.json).Path
go run ./cmd/api
```

也可在主项目本地 .env 中填写 MODEL_CONFIG_FILE。未设置时沿用原环境配置。显式私有文件中的字段优先于同名进程环境/.env 设置；未出现的字段沿用旧值。只允许白名单内的模型设置，不允许改数据库、Worker 凭据、来源权限、存储目录或递归配置路径。

Go 为报告和 ASR 使用同一份读取快照，不把文件密钥写入全局进程环境，也不传播到另行启动的 Python Worker。文件变更不会热更新；等待/取消活动任务并确认停止后重启。旧批次继续使用创建时保存的配置，不修改历史。

ASR_PLANNER、Worker 模型名称/修订、处理器版本及 FFmpeg 摘要仍按 [统一部署说明](音视频统一接入与收尾.md) 配置一致。该工具不代替 Worker 的安装和启动，也不会停止现有服务。

团队网页启动器继续使用原有 prepare 的 `--analysis-config <私有JSON>` 参数，无需再设置 MODEL_CONFIG_FILE；它已经支持同一文件结构。沿用原数据目录，不要为了切换配置重新创建课堂数据库。

30 元是应用侧共享预算，不是百炼账户或其他程序的总消费限额。现有服务按所选计费方式预留、真实 usage 结算；超预留账目及 unknown 状态继续阻断新调用并等待核对，不能承诺供应商账单绝不超过应用预算。可同时在供应商侧配置余额/告警。

真实调用仍须核对控制台价格、模型权限和供应商返回的 usage，再使用获准短样本验证。当前没有新增网页“任意厂商/模型选择”功能；配置由部署管理员管理。真实中文质量、长课堂速度与费用及 Linux/Docker 实机验收继续保留未完成状态。
