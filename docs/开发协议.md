# 开发协议 v1

文档 v0.6，2026-10-03。适用于 React、Go、Python Worker；接口尚待实现。实体见[数据库设计](数据库设计.md)，任务状态见[架构第5节](系统架构设计.md#5-任务阶段状态与恢复)。

## 1. 公共约定

业务前缀 /api/v1，Worker 前缀 /internal/v1。JSON 为 UTF-8、snake_case；UUID 为字符串，业务时间为带时区 RFC3339，播放位置为原始录像起点的整数毫秒。区间为 [start_ms,end_ms)，满足 0 ≤ start_ms < end_ms ≤ duration_ms；关键帧使用 timestamp_ms。

成功响应为 `{"data":...,"request_id":"..."}`，列表 data 为 `{"items":[],"next_cursor":null}`；错误为 `{"error":{"code":"...","message":"...","details":{}},"request_id":"..."}`。文件字节和204无 JSON 包装。null 表示缺失，unknown 表示未知说话人，未知置信度为 null。空数组是否因未完成产生须结合任务状态判断。

字段以[协议 Schema](../contracts/v1.schema.json)、[端点映射](../contracts/endpoints.json)及[样例清单](../contracts/examples/manifest.json)对应的 $defs 为准；通过结构校验后仍检查权限、ID 关联、时间上界及状态。端点映射列出每个请求、响应 data 和查询 DTO；multipart 的 file 表示文件字节，不能发送路径字符串。查询参数先解析整数再校验，未知字段拒绝。样例为独立合成场景，不能全部当作同批次结果导入。

列表 limit 默认20、范围1—100，游标不透明；按 created_at/id 稳定排序，无 created_at 的资源按 id 排序，筛选变化须清空游标。前端每2秒轮询活动批次，终态停止；显示阶段名与完成阶段数，不累加各阶段百分比。

### 1.1 认证与幂等

浏览器用同源 Cookie 会话（HttpOnly、SameSite=Lax，HTTPS 时 Secure）。GET /auth/csrf 获取与当前或登录前临时会话绑定的 token；写请求带 X-CSRF-Token 并检查 Origin，登录成功轮换会话和 token。前端按 allowed_actions 展示操作，后端逐次授权。

Worker 使用独立 Bearer 凭据，映射 worker_id 与可执行媒体阶段；入口限内部网络。任务相关接口还带 X-Lease-Token，读取和上传都重新校验。不得提交任意本地路径或外部下载 URL。

创建批次、导出、清理要求 Idempotency-Key（1—128个可打印 ASCII 字符）。服务端按用户、动作与课堂/报告命名空间保存，同键同规范化请求返回原资源200，同键不同参数返回409 IDEMPOTENCY_CONFLICT。幂等记录、请求摘要与审计随资源同事务保存；资源清理前保留。摘要规则和旧记录处理见数据库第4.5节。重放也先检查当前权限、课堂生命周期和来源；返回原资源不重新执行任务。所有业务 ID 由服务端生成。

### 1.2 状态码

| HTTP | code | 场景 |
| --- | --- | --- |
| 400 | INVALID_ARGUMENT | 字段、枚举或格式错误 |
| 401 | UNAUTHENTICATED | 会话或内部凭据失效 |
| 403 | FORBIDDEN / SOURCE_NOT_VERIFIED / EXTERNAL_PROCESSING_FORBIDDEN | 权限、来源或外部处理不允许 |
| 404 | NOT_FOUND | 不存在或超出可见范围 |
| 409 | SCHEDULE_CONFLICT / IDEMPOTENCY_CONFLICT / REVISION_CONFLICT | 排课、幂等或版本冲突 |
| 409 | LEASE_LOST / COMPLETION_CONFLICT / INVALID_STATE | 租约失效、完成内容变化或状态不允许 |
| 410 | RESOURCE_EXPIRED | 资源过期或旧版导出失效 |
| 413 / 415 | UPLOAD_TOO_LARGE / UNSUPPORTED_MEDIA | 超过大小或格式限制 |
| 416 | RANGE_NOT_SATISFIABLE | 单区间 Range 无效 |
| 422 | TIMELINE_INVALID / INVALID_RESULT / EVIDENCE_UNAVAILABLE | 时间轴、结果关联或证据无效 |
| 429 / 503 | TOO_MANY_REQUESTS / SERVICE_UNAVAILABLE | 限流或服务不可用，返回 Retry-After |

NO_AUDIO、NO_SPEECH、MODEL_TIMEOUT、MODEL_RESULT_UNKNOWN、BUDGET_EXHAUSTED 等异步错误写入 job/run.error_code；进度查询仍返回200。

媒体未 ready、到期或无播放许可时 playback_url=null；report_export 始终 playback_url=null，通用媒体内容端点对该 kind 返回403，不跟随父媒体或仅凭 playback 放行。导出字节仅由 /exports/{id}/content 返回；必须检查请求者、当前读取权限、export 许可、课堂状态、报告仍为当前发布版及导出期限。导出未成功或不可下载时 download_url=null。结果尚未生成的数组为空，并通过 run_status/jobs 区分等待与无结果。所有媒体读取均不暴露 object_key。

full 与 media_prepare 的 input_transcript_revision_id 必须 null，可对 pending 原媒体执行 probe；report_only 必须提供修订且原媒体 ready、未到期。full/report_only 须来源允许 analysis；media_prepare 须允许 playback，仅执行 probe，不提取音轨、采样、转写、建立证据或调用模型，成功时 report_id=null。config_profile 首期仅 p0-v1，模型与参数由 Go 固定为批次快照。主媒体选择与修订流程见架构文档。Session 返回 primary_media_asset_id、latest_run_id、current_report_id；无对应资源为 null，跳转后仍逐次鉴权。

review 的 submit 对整份 draft 提交复核；accept/revise/reject 仅在 in_review 下指定观察。accept 映射数据库 confirm；revise 表示确认已修正的观察，正文修改先 PATCH 再 submit。confirm_report 的 observation_id=null，提交当前 content_sha256；仅复核者在逐条处理后确认整篇摘要、六维摘要、证据及覆盖。其他动作 content_sha256=null。发布从 in_review 进入，整篇确认摘要须仍匹配；所有报告写入检查 lock_version。

PatchReport 使用 WritableObservation：已有观察提交原 id，新观察 id=null；禁止写 review_status、复核人等只读字段。Go 分配新 ID，保留未改观察的 ID/复核状态；修改观察重置 unreviewed；移除观察写 removed_at，保留审计。每次内容修改回到 draft 并清空整篇确认。模型使用 ReportCandidate/CandidateObservation，无业务观察 ID 和复核字段。summary、Dimension.summary 的事实内容分别引用 summary_evidence_ids；空摘要引用为空，无依据放在 limitation。报告返回 provenance，导出保留模型修订、提示词摘要、selection_version、输入清单摘要、覆盖、来源及证据可用性。ModelInput 的 limitations 为有界数组，跳过项使用计数摘要，不逐项追加未发送证据 ID。旧版无法补证的字段为 null、allowed_actions=[]，只读标记“历史记录未完成本版核验”。

### 2.1 基础资料与课表

基础资源提供 GET 列表/单条、POST 创建、PATCH 修改；id 只读，其他返回字段按资源 DTO。列表沿用 items/next_cursor。账号用 disabled、开课用 archived、课表用 cancelled；有引用的资料不能删除。

| 路径资源 | 可写字段 | 写权限 |
| --- | --- | --- |
| /org-units | parent_id,code,name,kind(school/college/department) | 系统管理员 |
| /users | org_unit_id,username,display_name,status；创建另带 initial_password | 系统管理员；教务仅本学院教师/督导 |
| /users/{id}/role-bindings | POST {role_code,scope_org_id}；DELETE /{binding_id} | identity 检查范围；教务不得改本人、管理员或超范围角色 |
| /terms | code,name,start_date,end_date | 系统管理员 |
| /courses | org_unit_id,code,name,description | 系统管理员/本学院教务 |
| /class-groups | org_unit_id,code,name,enrollment_year,expected_size | 系统管理员/本学院教务 |
| /classrooms | code,name,capacity | 系统管理员 |
| /offerings | org_unit_id,term_id,course_id,teacher_id,class_group_id,code,status | 系统管理员/本学院教务；有课堂后归属不可改 |
| /schedules | offering_id,classroom_id,starts_at,ends_at,status | 系统管理员/本学院教务；教师、班级从 offering 派生 |

GET /schedules 支持 teacher_id、classroom_id、class_group_id，以及 at 或 from/to（互斥）。指定单个教师、班级或教室时，一个时间点最多匹配一条 active 课表；响应仍用数组，未指定资源时可返回多条。

POST /schedules/import 接收 `{rows:[{offering_id,classroom_id,starts_at,ends_at}]}`，最多1000条，整批成功或回滚。冲突 details 为 `{resource_type,row_numbers,conflict_start,conflict_end}`，不暴露跨范围课表详情。

角色为固定枚举。教师读取本人开课引用资料，督导按学院读取；基础资料接口也须授权。

写入先解析全部关联 ID 的有效学院，再检查操作权限：课程、班级、开课同学院；教师 active 且有 teacher 角色，跨学院教师仅系统管理员可安排。学院教务操作用户须检查目标全部角色绑定，拒绝本人、任何管理员或跨学院授权账号。teacher 读取课程、班级和课表必须经本人 offering 可达；督导须经授权学院可达。上传的来源必须与课堂相同；派生媒体只能关联当前任务/租约/课堂。仅比较请求体 org_unit_id 不足以授权。

有课表无课堂时，更换教师/班级须延迟资源外键、同步全部课表并复查冲突后提交。已有课堂后开课归属和关联课表时间冻结，变更返回409 INVALID_STATE；新安排保留历史。禁止通过移动被引用组织、课程、班级间接改归属。ScheduleQuery 的 at 与 from/to 互斥，from/to 成对且 from<to；所有写入时间范围亦检查起止顺序。

## 3. Go 与 Python Worker

以下路径加 /internal/v1。Token 指 X-Lease-Token，任务ID与租约须匹配。

| 方法与路径 | 请求 | 响应 |
| --- | --- | --- |
| POST /jobs/claim | ClaimRequest：worker_id、capabilities | 200 Claim；无任务204，5秒后重试 |
| POST /jobs/{id}/heartbeat | Token；{progress:0..99} | 200 {lease_expires_at,cancel_requested:false}；取消/丢失租约返回409，Worker 停工 |
| GET /jobs/{id}/input | Token；Range 可选 | 200/206 指定输入媒体 |
| POST /jobs/{id}/artifacts | Token；multipart file、artifact_key、kind、timestamp_ms、origin_offset_ms | 201 {asset_id,sha256,byte_size}；同键同内容200，内容变化409 |
| POST /jobs/{id}/complete | Token；StageResult 原始 JSON 字节 | 200 {job_id,status:"succeeded",duplicate:false}；重复确认 duplicate=true |
| POST /jobs/{id}/fail | Token；{error_code,message,retryable} | 200 {job_id,status,next_retry_at}；Go 决定是否重试 |

Claim 指定输入、阶段参数、硬截止时间及租约。StageResult 按 stage 使用 ProbeResult、AudioResult、VideoResult，schema_version="1.1"。Claim.execution 固定 processor_version、ffmpeg_build_sha256、asr_model（不涉及 ASR 时可空）、parameters_sha256；Worker 不能执行该版本就 fail CONFIG_MISMATCH，不使用本地默认版本替代。结果回显实际 execution，Go 与任务 expected_execution_sha256 及 Claim 精确比对；AudioResult.model 必须等于固定 asr_model。P0 视频返回关键帧，events=[]、model=null。运行中修改环境配置只影响新批次。

产物 kind 按阶段限制为 probe→proxy、audio_analysis→audio、video_analysis→keyframe。artifact_key 使用“当前 lease_token/本地产物名”，仅为任务内标识，不是文件路径；同租约重传复用该键，新租约使用新前缀，旧产物由 Go 对账清理。结果中的资产须为当前租约已上传的产物，probe 的播放资产也可为原始输入；一律检查同课堂归属。

Go 对完成请求的原始 UTF-8 字节计算 SHA-256，Worker 重试保留原字节。先检查课堂/批次未取消、删除、到期且当前来源仍许可该阶段；已成功任务比较 last_completed_token 和 completion_digest，相同即返回原确认，不再校验已清空的活动租约。首次提交须持有效租约，同 token 不同内容返回 COMPLETION_CONFLICT。

Claim.rights_version 是可追踪快照，不替代当前许可；Claim.storage_generation 使清理前的读写失效。输入/产物/心跳/完成每次重新检查课堂、原媒体期限及来源；外部调用发送前、报告发布和导出生成/下载也重新检查。撤销 analysis 停止相应阶段；仅撤销外部许可保留已获准本地结果，停止新模型调用；已发请求只结算，不采纳迟到正文。失效任务返回 SOURCE_NOT_VERIFIED/RESOURCE_EXPIRED 或 LEASE_LOST，并清空租约、停止后续调度。

P0 统一 timeline：源容器公共起点 T0，所有流按 round_half_up((PTS×time_base−T0)×1000) 转为整数毫秒；音轨起点晚于 T0 时补静音，不独立归零。代理无裁剪、变速，origin_offset_ms=0，播放与源时间一致；负时间、非单调或无法映射拒绝 TIMELINE_INVALID。coverage 是实际处理窗口的有序不重叠数组，不等于发声区间，也不代表采样间连续发生事件；帧满足 0≤timestamp_ms<duration_ms，片段必须落在已处理窗口内。report_only 保留原时间坐标，不能根据修订文字重估时间。

## 4. 结果边界与协议变更

Worker 返回片段、帧和事件；业务 evidence_id 由 Go 生成。报告模型只引用输入中的 evidence_id，六维及观察结构见 Schema；受限维度保留原因，不生成无证据结论。

发送前将 ModelInput 精确序列化为不可变清单，存 job_artifacts.metadata（内部产物，不向普通读取端点暴露）；清单含最终截断后的证据 ID、原文、文本摘要、课程上下文、源/转写版本、模型修订、提示词摘要和实际覆盖。另存实际请求体 SHA-256；模板与参数也纳入批次快照。validate 校验候选全部引用属于该清单的子集，再检查同批次和当前可用性；同批次但没发给模型的证据也不可由候选引用。完整正文随课堂清理；纯账目不保留请求原文。

v1 Schema 严格限制字段及版本。协议变更须同步 Schema、成功/错误样例和受影响端，由前后端、音视频共同确认后联调；新增可选字段也不默认兼容旧校验器。数据库迁移另行编号，不直接把数据库列作为 API 字段。

本次契约版本1.1须整体替换旧 Mock；不能将1.0 Worker接入1.1完成端点。前端/API尚未实现，接入根 DTO 见 endpoints.json；api-cases.json 是独立合成请求/响应及反例，含 context 的案例表示服务端可信上下文，不能作为客户端参数发送。`python tools/check_docs.py` 同时运行结构、业务语义和端点样例覆盖检查，不代表已部署服务通过授权测试。
