# 非视频测试数据

本数据集 `nonvideo-v1` 服务于 FR-01 登录授权、FR-03 排课和 FR-03a 课堂目录联调。全部内容由程序合成，不包含真实师生、电话、邮箱、音视频、转写或模型分析结论。它是开发样例，不是教学质量验收结果。

## 内容

| 数据 | 本数据集数量 | 覆盖场景 |
| --- | --- | --- |
| 组织单位 | 6 | 学校、两个有数据的学院、一个空学院、两个系 |
| 账号及角色绑定 | 各14 | 系统管理员、两个学院的教务/督导、8名教师、1名禁用教师 |
| 学期 | 3 | 2025秋、2026春、2026秋 |
| 课程 | 8 | 仓颉程序设计、数据结构、数据库、软件工程、英语、文化、写作、教育心理学 |
| 班级 | 8 | 2024～2026入学年份，正常人数、0人、人数未知 |
| 教室 | 5 | 小班、标准、研讨、阶梯、容量未知 |
| 开课实例 | 12 | 8条当前学期有效记录、4条历史归档记录 |
| 课表 | 48 | 36条有效时段、12条取消安排，教师/班级/教室无有效冲突 |
| 课堂场次 | 44 | 24条待上课、20条归档；其中8条无课表关联；全部 is_demo=true |
| 来源登记 | 12 | 全部待核验，只含表单元数据，未批准外部处理或再分发 |

不插入媒体、采集记录、分析任务、转写、证据、报告、模型费用或导出结果。这些表依赖真实媒体及同课堂、同批次输入；不能伪造成功记录填充页面。现有契约样例可用于相关页面的固定JSON联调，但不能冒充数据库中的真实分析结果。

## 使用

在仓库根目录，先按 [README](../README.md) 完成环境配置和数据库迁移。本命令不自动迁移数据库。

只预览数据数量，不连接数据库，也不要求密码：

```powershell
go run ./cmd/seed-nonvideo
```

实际追加到 `.env` / 环境中的 `DATABASE_URL`：

```powershell
$env:APP_ENV = 'development'
$env:BOOTSTRAP_TEST_PASSWORD = '<本机设置12至72字节测试密码>'
go run ./cmd/seed-nonvideo -apply
Remove-Item Env:BOOTSTRAP_TEST_PASSWORD
```

仅允许 development/test，production和其他环境会被拒绝。密码通过环境变量读取并以bcrypt散列保存，不输出、不提交默认明文密码。密码按字节计长且不允许首尾空白。

全部记录使用独立 `TESTDATA_` 编码或 `testdata_` 用户名，名称带“合成测试”。独立样例学校不会改变已有账号的组织范围。已有系统管理员可见这些数据；原学院教务和教师看不到其他学院的样例属于正常权限行为。

### 测试账号

| 用户名 | 角色/范围 |
| --- | --- |
| testdata_admin | 全局系统管理员 |
| testdata_academic_1 / testdata_academic_2 | 合成计算机学院 / 合成人文学院教务 |
| testdata_supervisor_1 / testdata_supervisor_2 | 对应学院督导 |
| testdata_teacher_1 ～ testdata_teacher_8 | 各自开课的任课教师 |
| testdata_disabled | 禁用教师，预期不能登录 |

新建账号使用本次传入的同一本地测试密码。重复导入不重置已有密码、不覆盖编辑和状态，也不清空原数据。固定ID通过命名空间摘要生成；它们不是安全令牌。主键对应的样例账号身份发生变化时拒绝导入，编码/用户名被其他ID占用时也整体回滚，需人工明确处理，不自动认领或提权。

导入由事务和事务级锁保护。数量输出是本数据集的记录数量，不是数据库总数量。所有临时表在提交或回滚时清理。

## 验证

无需数据库的校验：

```powershell
go test ./internal/devseed ./cmd/seed-nonvideo
python tools/check_docs.py
```

完整验证使用**新建的独立空数据库**，测试不会清空已有库：

```powershell
$env:DEVSEED_TEST_DATABASE_URL = '<独立空测试库连接串>'
go test ./internal/devseed -run TestNonVideoFixturesPostgres -v
Remove-Item Env:DEVSEED_TEST_DATABASE_URL
```

该测试执行全部现有迁移，检查数量、幂等、密码有效及保持不变、编辑保留、组织角色范围、全量合成课堂标记、媒体关联表保持为空，以及身份冲突时事务整体回滚。为了避免误操作，已有 teaching schema 的数据库会被拒绝；重复运行该完整测试请使用新的空测试库。

排课数据固定在样例学期内，日期不随每次执行漂移，因此可以稳定比较前后导入结果。不会自动把待上课场次改成已发生或媒体就绪。
