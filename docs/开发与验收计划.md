# 开发与验收计划

文档 v0.5，2026-10-02。本文件规定开发顺序和验收方法；当前为文档、协议样例及 SQL 基线，业务服务尚待实现。

## 1. 环境与配置

首期同机部署 Go、Python Worker、PostgreSQL 和本地媒体目录，React 由 Go 或同源网关提供。共同集成环境为 Linux amd64 容器，P0 单 Worker、单重型任务；真实 CPU 推理必测，固定结果仅用于接口联调。

| 组件 | 项目基线 | 固定方式 |
| --- | --- | --- |
| Go | 1.26 系列 | 首个实现 PR 固定 toolchain 与镜像版本 |
| 前端 | Node.js 24 LTS、React 19 | engines、依赖锁文件及镜像 |
| Python | 3.12 | 镜像与依赖锁文件 |
| PostgreSQL | 17 系列、btree_gist | 镜像版本；迁移按001→002 |
| FFmpeg/ffprobe | 同一发行构建 | 视频成员固定版本并验证输入解码与 H.264/AAC 代理编码 |
| 模型 | 中文 ASR、文本报告模型 | M2 前固定模型 ID、修订/摘要、参数及提示词版本；P0 无行为模型 |

后端负责共同启动环境，数据库成员负责迁移，音频成员负责 Worker 公共入口，视频成员负责媒体处理，前端成员负责同源访问。修改公共版本须全组确认。

配置以 [.env.example](../.env.example)为准；启动时检查必填项。模型配置缺失或预算为0时跳过报告，保留本地分析。启动顺序为数据库→迁移与管理员初始化→Go→Worker→前端；具体命令随首个实现 PR 提交。/health/live 检查进程，/health/ready 检查数据库与存储。模型不可用显示能力受限。

## 2. 里程碑与协作

| 里程碑 | 完成条件 | 主责 |
| --- | --- | --- |
| M0 协议与环境 | 各组确认 Schema/样例；环境、启动入口及角色测试账号可复现 | 后端牵头，数据库及各组参与 |
| M1 固定样例联调 | 前端经 Go 展示任务、转写、证据和报告；Worker 经内部 API 提交固定结果 | 前后端、音视频 |
| M2 单录像真实分析 | 中文录像完成播放、真实 ASR、关键帧和报告；提交模型及质量测量结果 | 音频、视频、后端 |
| M3 修订发布 | 修正转写后新报告使用新文本；旧版可查；复核、发布、撤回、导出权限正确 | 前后端、数据库 |
| M4 故障与交付 | 重启、旧租约、重复回调、预算、删除并发及备份恢复通过验证 | 后端牵头，各组参与 |

每个交付项确定一名实际负责人。接口变更同 PR 更新 Schema、样例与消费者，受影响组确认；公共协议和迁移先合并，再合并依赖它们的功能。

## 3. 样本与质量验证

M1 用合成 JSON；M2 用有来源许可的中文课堂，覆盖清晰语音、专业术语、噪声/远场及连续长录像，并补充损坏、无音轨、无语音样例。音频成员维护样本清单，记录摘要、时长、来源许可、人工标注和开发/验证集划分。当前仓库不含这些真实样本。

| 项目 | 验证方法 |
| --- | --- |
| 转写 | 按统一去空白、标点规则计算 CER=(替换+删除+插入)/参考字符数，分场景报告，保留数字及专业词 |
| 时间定位 | 人工抽查起止点误差并报告 P95；所有片段在源时长内，无累计漂移 |
| 关键帧 | 使用配置中的间隔及上限，核对原视频定位；P0 events=[] |
| 报告 | 六维齐全；逐条核验证据与结论；驳回无依据观察，受限维度注明原因 |
| 性能 | 记录硬件、模型版本、输入时长/分辨率、各阶段耗时及内存/磁盘峰值 |
| P1 行为 | 启动时另行标注保留验证集，按事件类型评估 precision/recall 与视角限制 |

M2 根据样本和资源确认质量、耗时门槛，M4 用保留验证集复测；不把未经测量的数字作为现有能力承诺。

## 4. 需求验收对应

P0 均须完成应用联调；已有 SQL 或协议检查不能代替业务验收。

| 需求 | 主责 | 关键用例 |
| --- | --- | --- |
| FR-01 权限 | 前后端 | 教师越权、兼任督导、禁用会话及 CSRF |
| FR-02 基础资料 | 前后端、数据库 | 学院不能授予管理员、跨学院修改拒绝、有引用不可误删 |
| FR-03 课表 | 后端、数据库 | 教师/班级/教室分别冲突、相邻允许、并发及批量回滚 |
| FR-03a 目录 | 前后端、数据库 | 入学年份及未知值筛选、归档与删除区别 |
| FR-04 上传 | 前后端、视频 | 待核验拒绝分析/播放、上传中断及格式/大小/时长限制 |
| FR-05 回放 | 视频、前后端 | Range 206/416、pending→ready、浏览器跳转及代理时间映射 |
| FR-06 任务 | 后端、音视频 | 重启恢复、旧 token、重复确认、取消与完成竞态 |
| FR-07 转写 | 音频、后端 | CER、时间误差、未知说话人及无语音原因 |
| FR-08 报告 | 后端、音视频 | 六维、同批次引用、超长输入覆盖与虚构引用拒绝 |
| FR-09 复核 | 前后端、数据库 | 新修订生效而旧报告不变、并发版本冲突、发布权限 |
| FR-10 导出 | 前后端 | 固定版本、撤回或撤权后拒绝下载、过期证据无链接 |
| FR-11 治理 | 后端、数据库 | 预算并发、unknown 不盲重试、删除后迟到结果拒绝、备份清单 |
| FR-12～14（P1） | 后端、视频、前端 | 实施时验收摄像头断流/时间映射、行为纠正及趋势口径 |

## 5. 检查入口与范围

- 协议及文档：`python tools/check_docs.py`，检查20份成功/失败样例、本地链接、表格和代码块。
- SQL：按[数据库设计](数据库设计.md#6-执行与验证)执行，或 `node tools/check_schema.mjs <已安装的PGlite包目录>`。

协议检查依赖 Python jsonschema。001→002及约束检查已在 PGlite 0.5.8 / PostgreSQL 18.3 WASM 隔离库通过，共29张表；原生 PostgreSQL 17、多连接竞争、业务授权和真实模型效果仍待实现阶段验证。
