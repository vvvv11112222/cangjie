# 开发与验收计划

文档 v0.6，2026-10-03。本文件规定开发顺序和验收方法；当前为文档、协议样例及 SQL 基线，业务服务尚待实现。

## 1. 环境与配置

首期同机部署 Go、Python Worker、PostgreSQL 和本地媒体目录，React 由 Go 或同源网关提供。共同集成环境为 Linux amd64 容器，P0 单 Worker、单重型任务；真实 CPU 推理必测，固定结果仅用于接口联调。

| 组件 | 项目基线 | 固定方式 |
| --- | --- | --- |
| Go | 1.26 系列 | 首个实现 PR 固定 toolchain 与镜像版本 |
| 前端 | Node.js 24 LTS、React 19 | engines、依赖锁文件及镜像 |
| Python | 3.12 | 镜像与依赖锁文件 |
| PostgreSQL | 17 系列、btree_gist | 镜像版本；迁移按001→002→003 |
| FFmpeg/ffprobe | 同一发行构建 | 视频成员固定版本并验证输入解码与 H.264/AAC 代理编码 |
| 模型 | 中文 ASR、文本报告模型 | M2 前固定模型 ID、修订/摘要、参数及提示词版本；P0 无行为模型 |

后端负责共同启动环境，数据库成员负责迁移，音频成员负责 Worker 公共入口，视频成员负责媒体处理，前端成员负责同源访问。修改公共版本须全组确认。

配置以 [.env.example](../.env.example)为准；启动时检查必填项。模型配置缺失或预算为0时跳过报告，保留本地分析。启动顺序为数据库→迁移与管理员初始化→Go→Worker→前端；具体命令随首个实现 PR 提交。/health/live 检查进程，/health/ready 检查数据库与存储。模型不可用显示能力受限。

新增配置必须随首个实现落地启动校验：具媒体能力的 Worker 固定 WORKER_PROCESSOR_VERSION/FFMPEG_BUILD_SHA256；具 ASR 能力还须 ASR_MODEL_NAME/PATH/REVISION；报告能力固定 REPORT_MODEL/REVISION、PROMPT_VERSION/SHA256、SELECTION_VERSION 和价格版本及单价。版本为空不能用“latest”代替。阶段超时不得短于租约，心跳须短于租约；上传/派生文件受大小和总时限限制。WORKER_TEMP_ROOT 按任务/租约隔离并清扫；DELETION_LEDGER_PATH 必须持久、可刷盘且不随业务备份回滚，重放未完成时 readiness=false。迁移前停写、备份并核对历史预检；003 的 NOT VALID 租约/账目约束不会伪造旧记录，启动前须处理旧活动任务和不完整账目并验证约束。

## 2. 里程碑与协作

| 里程碑 | 完成条件 | 主责 |
| --- | --- | --- |
| M0 协议与环境 | 各组确认 Schema/样例；环境、启动入口及角色测试账号可复现 | 后端牵头，数据库及各组参与 |
| M1 固定样例联调 | 前端经 Go 展示任务、转写、证据和报告；Worker 经内部 API 提交固定结果 | 前后端、音视频 |
| M2 单录像真实分析 | 中文录像完成播放、真实 ASR、关键帧和报告；提交模型及质量测量结果 | 音频、视频、后端 |

每个交付项确定一名实际负责人。接口变更同 PR 更新 Schema、样例与消费者，受影响组确认；公共协议和迁移先合并，再合并依赖它们的功能。

## 3. 样本与质量验证

M1 用合成 JSON；M2 用有来源许可的中文课堂，覆盖清晰语音、专业术语、噪声/远场及连续长录像，并补充损坏、无音轨、无语音样例。音频成员维护样本清单，记录摘要、时长、来源许可、人工标注和开发/验证集划分。当前仓库不含这些真实样本。

| 项目 | 验证方法 |
| --- | --- |
| 转写 | 按统一去空白、标点规则计算 CER=(替换+删除+插入)/参考字符数，分场景报告，保留数字及专业词 |
| 时间定位 | 人工抽查起止点误差并报告 P95；所有片段在源时长内，无累计漂移 |
| 关键帧 | 使用配置中的间隔及上限，核对原视频定位；P0 events=[] |
| 报告 | 六维齐全；逐条核验证据与结论；驳回无依据观察，受限维度注明原因 |
| 性能 | 记录硬件、模型版本、输入时长/分辨率、各阶段耗时及内存/磁盘峰值 |
| P1 行为 | 启动时另行标注保留验证集，按事件类型评估 precision/recall 与视角限制 |

已确认的暂定质量门槛见 [quality-gates.json](../contracts/quality-gates.json)：清晰语音 CER≤15%，噪声/远场 CER≤30%，人工标注起止点绝对误差合并计算的 P95≤1500ms。CER 按场景汇总编辑距离/参考字符数；去 Unicode 标点及空白，保留数字和专业词；P95 使用 nearest-rank，时间区间必须在源时长内。M2 和 M4 均使用冻结的保留验证集，不能用开发集调参后宣称通过。这些是验收目标，尚无真实结果。

测量入口为 `python tools/check_quality.py <受控本地评测.json>`。输入含 split="held_out"、dataset_sha256、synthetic 布尔值及 samples 数组；每个样本含 id、scenario（clear/noisy）、reference、hypothesis、duration_ms、timings。timings 每项含 reference_start_ms/reference_end_ms/actual_start_ms/actual_end_ms，均为整数毫秒。两种场景均须有样本及人工时间标注；禁止空参考或缺场景充当通过。成功退出0表示度量达标且非合成数据；合成数据即使指标合格仍退出1，字段 acceptance_passed=false。输入文本、授权证明和原媒体保留在受控位置，不提交仓库；输出只含指标及集合摘要。样本真实性、许可和独立划分仍由音视频负责人核对。

连续长录像抽查开头、中间、末尾以检测漂移；损坏/无音轨/无语音单列功能用例，不混入非空语音 CER。性能记录实际 CPU、模型、输入与资源峰值，硬超时须符合配置，不以本次合成测试宣称推理性能达标。

### 4.1 故障和权限用例的判定标准

以下为 Go/Worker 实现时必须执行的集成用例。每例保留请求、响应、数据库行和存储核验记录；当前仓库无服务，不能把此表计作已通过。

| 用例 | 操作和故障注入 | 必须观察到的结果 |
| --- | --- | --- |
| A01 范围 | 教师读他人课程/班级/媒体；教务修改带跨学院或管理员角色的目标；错学院课程创建开课 | 404/403；跨关联写入拒绝；无越权数据返回、无新行 |
| A02 只播放 | 来源仅 playback，上传后创建 media_prepare | 只一个 probe；媒体 ready、可授权播放；run succeeded、report_id=null，无 ASR/模型调用 |
| A03 导出绕过 | 猜到 report_export 的 media id，调用通用 content；撤回后用旧导出链接 | 通用端点403；旧导出410；两者均无文件字节 |
| A04 发现与刷新 | 上传两份媒体、多个来源及批次后刷新前端 | 可分页找回全部授权历史；Session 的三个当前引用准确；无越权入口 |
| A05 摘要复核 | 删除摘要证据；确认整篇后修改一个字；观察未确认时发布 | 拒绝无依据摘要；整篇确认清空；发布409/422；审计仍在 |
| A06 竞争发布 | 两草稿都预期当前版 R0，A先发布，B再发布 | A成功；B返回409 REVISION_CONFLICT；当前版仍A，R0只读 |
| A07 幂等 | 相同用户/课堂/键重复；改变参数；另一课堂复用键；换配置后重放 | 原请求返回原ID；改参数409；跨课堂不误冲突；不二次执行 |
| A08 预算 | 并发接近月限预留；预留后跨月；发送标记后断网/杀进程 | 总预留不越限；未发送预留移入新账期；已发送 unknown 保留额度；新键不能绕过 |
| A09 对账 | 管理员带旧 lock_version 对账；确认失败但有收费账单 | 旧版本409；failed 可保留非零 actual_cost；清理课堂后仍可核对 |
| A10 最后尝试 | 第3次媒体任务丢心跳；持续心跳但超过硬截止；report断线 | 任务明确 failed；清空租约；依赖 skipped、批次终态，无 waiting；report 不重发 |
| A11 治理恢复 | 导出写到一半、清理一个步骤后杀 Go | 重启以新token恢复；旧token提交失败；无重复导出；清理从清单续做 |
| A12 执行版本 | Worker替换模型/FFmpeg或回传不同参数摘要 | CONFIG_MISMATCH/INVALID_RESULT；无结果入库；新配置仅用于新批次 |
| A13 实际输入 | 超长文本截断后，候选引用同批次但未发送的 evidence_id | validate失败，不出现可读报告；实际请求与清单摘要可重建 |
| A14 时间轴 | 非零音轨起点、变帧率、末帧、越界片段、report_only修订 | 共用源T0，无独立归零；越界/不可映射拒绝；代理、帧、转写跳转一致 |
| A15 撤权到期 | 分别在领取后、上传中、模型已发、导出生成中撤许可/到期 | 后续输入/上传/完成/发布/下载拒绝；停后续调度；已发调用仅结算 |
| A16 删除并发 | 阻塞一个上传句柄后发起清理，再放行旧写入；Worker离线 | 旧代次不能登记；Worker无回执时blocked；所有暂存及正式对象核验后才succeeded |
| A17 备份恢复 | 删除成功后恢复删除前数据库/媒体备份；删除日志暂不可读 | 日志不可读时ready=false；可读后先重放，旧内容始终不可访问 |
| A18 审计与迁移 | 删除已复核观察；对共享来源旧库运行003 | 普通删除失败、软移除保留历史；按课堂拆分pending且无继承许可 |
| A19 课表修改 | 无课堂时同步教师/班级制造冲突；已有课堂后改时间/归属 | 冲突事务整体回滚；无冲突同步成功；有课堂后409且历史不变 |

## 5. 检查入口与范围

- 协议及文档：`python tools/check_docs.py`，检查结构、业务语义、全部端点 DTO 样例覆盖、本地链接、表格和代码块。
- SQL：按[数据库设计](数据库设计.md#6-执行与验证)执行，或 `node tools/check_schema.mjs <已安装的PGlite包目录>`。
- 质量计算器：`python -m unittest discover -s tools -p test_quality.py -v`，覆盖 CER/P95 边界、缺样本及越界；不是真实模型验收。
- HTML 草图：`node tools/check_prototype.mjs`，检查脚本语法及实际内联函数中的权限、冲突、复核、导出和待核验来源；不替代浏览器视觉检查。

协议检查依赖 Python jsonschema。001→002→003及约束检查、带数据旧库升级已在 PGlite 0.5.8 / PostgreSQL 18.3 WASM 隔离库通过，共29张表；升级检查覆盖非空旧 coverage/重复报告尝试的阻断、共享来源拆分及历史保留。原生 PostgreSQL 17、多连接竞争、业务授权、实际文件/Worker清理、浏览器联调和真实模型效果仍待实现阶段验证。
