# 上传录像、分析举手低头、查看个人画面

本指南对应团队系统的真实接口模式，沿用原有页面。第一次建议用几秒短片熟悉操作，再分析长录像。

## 1. 打开并登录

双击仓库根目录的 `启动团队网页.bat`，打开 `http://127.0.0.1:8088/#/sessions`。使用部署时创建的账号；本机账号说明保存在所选数据目录的 `使用说明.txt`，不要把该文件发到 GitHub。

## 2. 准备课堂与录像来源

在“课堂档案”选择已有课堂，或者按实际课程新建课堂。

第一次使用该课堂的录像时，到左侧“素材与来源”：

1. 选择同一节课堂，点“登记新素材”。
2. 填写录像名称、真实来处和许可说明；申请实际需要的“回放”“分析”。本机视觉分析无需勾选外部文本模型，也无需导出。
3. 有核验权限的人根据实际许可保存核验结果。登记不等于取得许可；不确定的用途不要批准。

来源是“这份录像从哪里来、允许做什么”的说明。同一课堂可以复用已有来源；另一课堂须使用属于它自己的来源。

## 3. 上传并开始视觉分析

1. 在课堂档案点击该课堂的“上传录像 →”，进入详情。
2. 在“批次与操作”点击“上传录像”，选择文件、按名称选择已登记来源，点“提交上传”。也可在“素材与来源”直接上传。
3. 上传后，在“处理目标媒体”选中这次录像。从来源页面上传或重新打开课堂后，可能需要手动选一次。
4. 点击 **“举手与低头分析”**。即使录像还在等待媒体检查，也可直接点击；系统会先检查和准备录像，再做视觉分析。
5. 页面会切到“视觉观察”，完成后自动显示结果。较长录像需要等待，不要重复提交相同录像。

“提交分析”是转写和教师报告的另一条流程，依赖音频与报告配置。只看举手、低头时使用“举手与低头分析”。上传成功只代表录像存进了系统，并不代表已经完成识别。

## 4. 查看某个人什么时候举手或低头

1. 打开课堂详情的 **“视觉观察”**；有多次分析时先选择对应记录。
2. 播放器右侧点击人物编号，例如 T0004。
3. 下方“筛选动作”选择 **“发现举手”** 或 **“发现低头”**。
4. 每一行是系统实际检查过的一张画面。点 **“定位录像”**，会跳到该时间并滚动回播放器。
5. 展开“查看这个时刻的证据图片”，可以核对原画面；图片不可用时仍可查看录像。

如果录像来源只允许“分析”，判断结果仍会保存：选择人物后，左侧直接显示各次检查的时间和判断，可筛选举手或低头。此时不能播放录像或读取证据图片，按钮显示“查看记录”。

需要边看录像边核对时，登记来源时应同时申请“回放”“分析”，再按实际许可核验。只申请过“分析”的旧来源，当前系统不能追加未申请用途；需重新登记包含回放用途的来源并上传录像，旧分析记录保留。不要通过改播放地址绕过用途限制。

编号仅用于这次录像，遮挡或切镜可能使同一个人更换编号，不能直接当成学生学号。

| 画框颜色 | 含义 |
| --- | --- |
| 红色 | 这次检查发现举手 |
| 蓝色 | 这次检查发现低头 |
| 绿色 | 这两种动作都未发现 |
| 灰色 | 至少一种动作看不清，且未发现举手或低头 |

选中人物不会改变动作颜色。在播放器上方勾选 **“显示所有人物框”**，即可同时查看当前检查画面中所有已检出人物的框，右侧同步显示各人的判断。首次需要读取已保存的记录，页面会显示进度；读取完成后播放和拖动录像使用缓存，不会重新分析视频。取消勾选后回到只画选中人物，再次勾选可直接使用缓存。

画框读取失败时可以重试，个人记录仍可查看。切换批次或离开页面后会清除该视图缓存。没有回放许可时不能显示录像框，但分析时间表仍可读取。该开关不补出原模型漏检的人，也不在分析等待期间直播检测画面。

默认每隔0.5秒检查一次，**不是视频的每一帧都检测**。一行“发现举手”不等于举了一次手；相邻多行也可能是同一次持续举手。低头可能是在阅读、写字，不直接等于不认真。可见人数、人物编号数量也不等于出勤人数。

## 5. 找不到结果时先看这里

| 看到的情况 | 下一步 |
| --- | --- |
| 上传后没有识别结果 | 选择处理目标媒体，再点“举手与低头分析” |
| 分析按钮不能点 | 先选择录像，检查来源是否已核验且允许分析 |
| “发现举手”筛选没有行 | 换人物检查；有“继续读取这个人的记录”时先读取剩余记录。空筛选不证明整段录像没人举手 |
| 有编号但灰框很多 | 该人物手臂、脸部太小或被遮挡，系统无法可靠判断 |
| 没有画框 | 先定位某一条记录；未加载或未检查的时间不补画框 |
| 历史录像看不到 | 核对课堂、处理录像和视觉分析记录是否选对 |
| 课堂处于“彻底清理中” | 已停止提供内容读取；不要继续对这节课堂上传或分析，改用其他课堂。清理失败需由管理员排查 |

“彻底清理课堂”用于永久移除整节课堂及相关内容，不能用作清空筛选或重做分析。需要再分析时创建新批次；只是暂时不想显示课堂时使用归档。

安装、停止、配置及验收限制见 [本机部署说明](README.md)。
